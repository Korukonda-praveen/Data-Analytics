A structured, end-to-end repository documenting my hands-on journey in **Data Analytics**. This workspace brings together core programming fundamentals, Object-Oriented Programming (OOP), relational database design, statistical probability modeling, and exploratory data analysis (EDA) with visual storytelling.

---

## 🎯 Repository Objectives

- **Build Strong Foundations:** Master Python programming constructs, modular coding, and OOP principles before scaling into data manipulation.
- **Query & Model Data:** Design normalized MySQL schemas and write analytical SQL queries to answer real-world business questions.
- **Apply Statistical Reasoning:** Solve probability and descriptive statistics problems to support data-driven hypothesis testing.
- **Clean, Analyze & Visualize:** Perform end-to-end EDA on real datasets (such as sales and diamonds datasets) using NumPy, Pandas, Matplotlib, and Seaborn.
